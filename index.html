Read-only command console

Send raw ELM327 or OBD requests. Only read services (01, 02, 03, 06, 07, 09, 0A) and info AT commands are allowed. Everything else is blocked by the server.

Mode

The tool starts and stays in read-only mode. It never sends a write to the car on its own.

The only write it supports is OBD Mode 04: clear trouble codes & turn off the check-engine light. You have to arm it here yourself, and it disarms after one action or 2 minutes.

Clear trouble codes (Mode 04)

Before you clear:

  • Fix the underlying fault first. Otherwise the code comes back.
  • Clearing also wipes freeze-frame data and resets every readiness monitor to "not ready". Monitors need roughly 1–3 normal drive cycles to complete again.
  • Permanent codes (Mode 0A) can't be erased this way. The ECU clears them itself after it confirms the repair.
  • Ignition ON, engine OFF. The server refuses if it sees RPM.
